# Design system & accessibility

## Principles

1. **Calm, not clinical.** Soft neutral background, white cards, one confident indigo accent.
2. **One glance, one action.** Every tab leads with the most useful number and the next action.
3. **Never color alone.** Range status is always color + icon + words ("Below range", "In range",
   "Above range").
4. **Honest about data.** Fictional data is labelled everywhere it appears; safety notes are
   short, plain and persistent.

| `background` | `#F4F6FA` | `#0A0E17` | Screen background |

| `text` / `textSecondary` | `#0D1424` / `#4D576A` | `#F3F5F9` / `#B1B9C9` | Body / supporting text |
| `primary` | `#3451D1` | `#8EA2FF` | Actions, selection |
| `inRange` | `#147A46` | `#4ADE94` | In target range |
| `below` | `#B42318` | `#FF8A80` | Below target range |

| `demo` | `#6941C6` | `#C3B1FF` | Fictional sample data |

Spacing is a 4-pt scale (`xs 4 … huge 48`); radii `8 / 12 / 16 / 22`. Type ramp: display 56,
large title 32, title 24, title2 20, headline 17, body 16, callout 15, subhead 14, footnote 13,
caption 12. Numbers use tabular figures.

## Accessibility checklist (implemented)

- Touch targets ≥ 44 pt (most controls 48 pt).
- Every button, switch and tab has an accessible name; enforced by `expectAllControlsLabelled()`
  in screen tests.
- Text scales with the system font size (Dynamic Type / Android font scale). Only the 56-pt
  glucose numeral and large titles are capped (1.6×) so layouts stay usable; everything else
  allows up to 2.4×. Rows wrap instead of truncating where possible.
- Charts have a full text alternative (count, average, lowest, highest, % in range).
- Segmented controls are exposed as tab lists with selected state; steppers and the time picker
  are "adjustable" for VoiceOver/TalkBack swipe gestures (on web they degrade to labelled buttons).
- Inline form errors are announced (`accessibilityRole="alert"` / live region).
- Dark mode with its own contrast-checked palette; choice of System / Light / Dark.
- Automated axe-core scans (WCAG 2.0/2.1/2.2 A & AA) run on 11 screens in the E2E suite with
  zero serious or critical violations.
